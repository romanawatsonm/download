📖 安装说明

  1. 点击 "安装描述文件" 按钮
  2. 弹出提示后点击 "允许"
  3. 前往 设置 → 通用 → VPN与设备管理
  4. 找到 "TikTok设备授权" → 点击 安装
  5. 返回此页面，点击 "安装应用"
  6. 安装完成后，再次前往 设置 → 通用 → VPN与设备管理 → 信任证书
  7. 若打开 App 提示"需要开发者模式"，前往 设置 → 隐私与安全性 → 开发者模式，打开开关并按提示重启设备
